MR阳性 + coloc阴性的含义:
  • OLR1→AAA的因果效应可能通过间接通路实现（而非cis-eQTL直接调控）
  • 提示存在中介机制：OLR1 → 炎症介质 → AAA
  • 支持开展中介MR分析以检验特定中介通路

五、综合解读与研究意义

核心发现

  1. OLR1 → AAA 总效应阳性（IVW OR=1.0023, p=0.022）: OLR1表达升高增加AAA风险
  2. 共定位阴性（PP.H4 < 2%）: 提示间接通路而非共享因果变异
  3. IL6R → AAA 强保护效应（OR=0.722, p≈3e-26）: IL6R信号通路是AAA的关键调节者
  4. CRP → AAA 无效应（p=0.58）: 全身非特异性炎症标志物不介导AAA发病

机制假说

LOX-1（氧化型LDL受体1）在血管内皮细胞和巨噬细胞中表达，其表达升高通过以下机制促进AAA：

  1. 直接效应: LOX-1 → ROS产生 → 内皮功能障碍 → 血管壁降解
  2. 炎症通路: LOX-1 → NF-κB激活 → 促炎细胞因子(MMP-2/9, IL-1β) → 弹性蛋白/胶原降解
  3. IL6R通路（本研究支持）: LOX-1可能调节IL6R信号，而IL6R trans-signaling对AAA具有保护作用。 IL6R阻断（如tocilizumab）可能增加AAA风险，这与临床观察一致

共定位阴性 + IL6R显著 → OLR1可能通过trans-pQTL效应（远端调控IL6R水平）而非cis-eQTL直接 影响AAA风险，这解释了为何MR阳性但coloc阴性。

局限性

  1. Step 1 缺失: 当前缺少OLR1→IL6R的直接效应估计（需要完整的中介物GWAS summary stats）， 无法计算中介效应比例（proportion mediated）
  2. pQTL效应值来源: IL6R pQTL效应值来自文献估计（β≈0.5 SD），非直接从GWAS summary获取， 为近似值
  3. LD结构: IL6R的4个SNP高度连锁（均标签rs2228145功能变异），有效独立信息有限
  4. 组织特异性: OLR1在Artery_Aorta无显著eQTL，使用血液/冠状动脉/胫骨动脉eQTL替代
  5. 未进行LD clumping: OpenGWAS API不可用，使用10kb窗口手动clumping，可能遗漏远端LD

后续建议

  1. 补全Step 1: 获取IL6R/CRP的完整GWAS summary stats（如SCALLOP联盟、UKB-PPP）， 用OLR1 eQTL工具变量做OLR1→IL6R的MR，计算中介效应比例
  2. 扩展中介物: 检验MMP-2、MMP-9、TNF-α、IL-1β等AAA关键炎症介质
  3. 多组织eQTL: 使用GTEx Aorta组织（如有显著eQTL）或单细胞eQTL数据
  4. 实验验证: 在LOX-1过表达/敲除小鼠AAA模型中检测IL6R信号通路变化
  5. 临床转化: 评估EVAR术后患者血清sIL6R水平与瘤囊炎症/内漏的关联
